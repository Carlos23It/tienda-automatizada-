🛒 Tienda Automatizada
Proyecto de desarrollo de una tienda inteligente y completamente automatizada que permite a los clientes realizar compras de forma autónoma mediante una aplicación móvil. El sistema integra identificación por códigos QR, escaneo de productos, gestión de inventario en tiempo real, procesamiento seguro de pagos electrónicos y generación automática de tickets digitales.

La solución elimina la necesidad de cajas tradicionales y personal de cobro, ofreciendo una experiencia de compra rápida, moderna y segura. Además, incorpora mecanismos de control de acceso mediante puertas automatizadas, monitoreo en tiempo real y protocolos de emergencia para garantizar la seguridad de los usuarios y la continuidad operativa del servicio. 

Características
Autenticación e identificación mediante códigos QR.
Control automatizado de acceso y salida.
Escaneo de productos desde dispositivos móviles.
Gestión dinámica del carrito de compras.
Consulta y actualización de inventario en tiempo real.
Integración con sistemas bancarios para pagos electrónicos.
Emisión automática de comprobantes digitales.
Monitoreo de incidencias y alertas para soporte técnico.
Protocolos de seguridad y respuesta ante emergencias. 
Objetivo
Desarrollar una plataforma de compra autónoma que optimice los procesos comerciales mediante la automatización, reduzca los tiempos de atención y brinde una experiencia eficiente tanto para clientes como para administradores.
